# Summary: Axoloti-to-Daisy Shim Layer

## What This Is

A compatibility layer (shim) that allows C++ patch code generated by the Axoloti/Ksoloti/Akso patcher to compile and run on Electro-Smith Daisy Seed hardware instead of the original Axoloti/Akso boards.

## Architecture

```
┌─────────────────────────────────────────────────────────┐

│  - Uses Q27 fixed-point arithmetic                     │
└───────────────────────┬─────────────────────────────────┘
                        │ includes axoloti_compat.h
┌───────────────────────▼─────────────────────────────────┐
│  Shim Headers (src/)                                    │

│  - axoloti_math.h      — ARM intrinsics + lookup tables │
│  - axoloti_filters.h   — biquad DSP functions           │
│  - parameters.h        — ParameterExchange_t structs    │
│  - parameter_functions.h — clamp/scale functions        │
│  - midi.h              — MIDI types and defines         │
│  - patch.h             — patchMeta_t, function typedefs │
│  - codec.h             — audio buffer externs           │
│  - axoloti_memory.h    — sdram_malloc/free API          │
│  - gpio_mapping.h      — palSetPad → HAL mapping        │
│  - axoloti.h           — master include                 │
│  - axoloti_compat.h    — replaces original xpatch.h     │
└───────────────────────┬─────────────────────────────────┘
                        │ linked with
┌───────────────────────▼─────────────────────────────────┐
│  main.cpp (Daisy entry point)                           │
│  - DaisySeed init, audio block=16, SR=48kHz             │

│  - Lookup table generation at startup                    │

└───────────────────────┬─────────────────────────────────┘
                        │ links against
┌───────────────────────▼────────────────────────────────┐
│  libDaisy (libdaisy.a)                                 │
│  - Hardware abstraction for STM32H750                  │
│  - SAI audio, GPIO, UART, ADC, SDRAM, DMA              │
└────────────────────────────────────────────────────────┘
```

## How It Works

1. **Boot**: `main()` initializes Daisy hardware, sets audio to 16-sample blocks at 48kHz
2. **Tables**: Lookup tables (sine, pitch, window, exp, log, BLEP) are computed at startup
3. **Patch init**: `xpatch_init(0)` is called, which creates the root patch object
4. **Audio loop**: Every 16 samples:
   - Daisy float input → Q27 interleaved buffer (`rbuf[]`)
   - `PatchProcess(rbuf, buf)` runs the patch DSP
   - Q27 interleaved buffer (`buf[]`) → Daisy float output
5. **MIDI**: Main loop polls UART MIDI, converts events to `PatchMidiInHandler()` calls - Untested

## Coverage

- **~86% of Axoloti object library** is portable (CLEAN + NEEDS_MAPPING categories)
- **~14% is blocked** (display, SD card, USB host — missing hardware)
- All pure DSP objects work without modification
- MIDI, parameters, delays, and noise generators work through the shim
